# Installation simple

1. Copiez tout le contenu de ce kit dans votre dossier local `JMH95200_Workspace_V6`.
2. Acceptez la fusion avec les dossiers existants.
3. Ouvrez GitHub Desktop.
4. Dans Summary, écrivez : `Sprint 1 - serveur V6 initial`.
5. Cliquez sur `Commit to main`.
6. Cliquez sur `Push origin`.
7. Sur GitHub, ouvrez l'onglet `Actions`.
8. Attendez la coche verte de `Construire le serveur Docker`.

Cette empreinte vérifie l’identité du NAS. Elle ne contient aucun mot de passe. Si vous changez de serveur, utilisez son certificat valide ou son empreinte vérifiée.

Partage : JMH · DNS : automatique

Le VPN, déjà configuré.

JMH utilisera la sortie VPN préparée sur votre NAS. Aucune clé privée n’est copiée dans cet installateur.

Un proxy ne couvre pas tous les protocoles réseau. Sous Linux, ce réglage concerne JMH ; les autres applications gardent leur connexion habituelle.

Le VPN reste désactivé après installation. Activez-le dans JMH quand vous le souhaitez. S’il est protégé, JMH demandera ses identifiants au NAS après votre connexion autorisée.

Tout est prêt.

La configuration NAS et VPN sera enregistrée sur cet ordinateur.

« Terminer » teste le NAS et le proxy avant d’enregistrer. Vous pouvez revenir modifier leurs adresses sans perdre vos réglages.

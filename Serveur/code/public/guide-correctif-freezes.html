Correctif JMH : freezes et lecteur cinéma

2 octobre 2026 · Version 5.1.2 — correctif 2026.10.02.3

1. Installer sur le PC fixe

  1. Ouvre JMH sur le PC fixe et connecte-toi comme d’habitude.
  2. Ouvre Mises à jour dans le menu à gauche.
  3. Vérifie que la version publiée est 5.1.2 · build 2026.10.02.3, puis clique sur Installer depuis le serveur. Le téléchargement et la vérification se font depuis ton NAS.
  4. JMH se ferme pour l’installation. Dans l’installateur, clique sur Installer, attends la fin, puis rouvre JMH. La mise à jour peut aussi se proposer au prochain lancement après connexion.
  5. Si le bouton n’apparaît pas, clique sur Télécharger l’installateur depuis le même écran et ouvre le fichier téléchargé sur le PC fixe. L’installateur présent sur le bureau du portable s’appelle JMH95200-Setup-2026.10.02.3.exe.

2. Analyser le gel complet de Windows

Plusieurs blocages réels de JMH ont été corrigés. Un gel de tout Windows doit encore être examiné à partir du PC fixe : il ne suffit pas de tester sur le portable.

  1. Après installation, dans JMH sur le PC fixe, ouvre Cet ordinateur.
  2. Clique sur Envoyer le diagnostic à mon NAS. Attends le message Diagnostic reçu sur ton NAS.
  3. Préviens-moi dans cette conversation que le diagnostic a été envoyé. Je pourrai consulter les erreurs Windows récentes, les pilotes, la mémoire, les températures disponibles et les incidents de JMH.

Ce bouton envoie le diagnostic uniquement à ton NAS, dans un dossier privé accessible au compte administrateur. Aucun envoi automatique. Exporter le diagnostic Windows permet de conserver une copie sur le PC.

3. Utiliser le lecteur cinéma

  • Retour à la bibliothèque : visible en haut du lecteur, arrête le film et revient à la collection.
  • −10 s / +10 s et la barre de position : reculer ou avancer.
  • Qualité : image originale pour les vidéos compatibles ; 720p ou 1080p quand le fichier le permet. Une source 4K compatible propose l’original 4K. Un fichier basse définition ne peut pas devenir une vraie vidéo 4K.
  • Audio : choisir la piste ou la langue disponible dans le fichier.
  • Voix plus présentes : réduire les écarts entre sons forts et faibles pour mieux entendre les dialogues. Ce réglage prépare le son sur le NAS.
  • Volume, Couper le son, Vitesse, Plein écran : commandes accessibles sous l’image. Le retour reste visible en plein écran sur les navigateurs compatibles.

Lors d’un changement de qualité, de piste ou de position dans un format converti, le NAS prépare un nouveau flux. Si la lecture hésite, choisis 720p. Les choix dépendent du fichier et des capacités du navigateur.

4. Ce qui a été vérifié

Lecture et déplacement dans le film, pistes audio, 720p, 1080p et original 4K testés sur le NAS. Bibliothèque de 13 239 titres testée : tri allégé et passage au morceau suivant sans attendre l’enregistrement de la position. Accès réseau Windows asynchrones et limités dans le temps. Le gel complet de Windows sur le PC fixe reste à diagnostiquer.

Les fichiers du disque externe sont conservés. Tes anciens tutoriels restent sur le bureau.

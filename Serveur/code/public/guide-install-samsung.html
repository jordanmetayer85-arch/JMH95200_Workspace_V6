Installer JMH sur Samsung

Tes adresses à conserver

Application : https://jmh-nas.tailee93eb.ts.net
Fichiers du NAS : smb://100.80.184.88
Partage Windows : \\100.80.184.88\JMH

Active Tailscale sur l’appareil avant d’utiliser ces adresses.

JMH s’installe comme une application web : une icône JMH, puis une fenêtre indépendante. Le navigateur est utilisé une seule fois pour l’ajouter. La bibliothèque reste sur le NAS ; elle n’est pas copiée entièrement sur le téléphone.

Avant l’installation

  1. Le NAS est déjà configuré. Le tutoriel Accès NAS depuis l’extérieur explique comment connecter tes appareils au réseau Tailscale.
  2. Installe Tailscale depuis le magasin d’applications du téléphone. Connecte-le à ton réseau Tailscale. Pour ta copine, invite son propre compte depuis la console Tailscale plutôt que de partager ton mot de passe.
  3. Active Tailscale. Sur l’iPhone, accepte l’ajout de la configuration VPN quand iOS le demande.
  4. Dans la page Accès à distance de JMH, récupère l’adresse HTTPS affichée après la liaison du NAS. Conserve cette adresse pour chez toi et ailleurs. L’ancienne adresse 192.168.1.27 ne fonctionne que chez toi.

Installer JMH sur le Samsung

  1. Ouvre Google Chrome sur le Samsung et saisis l’adresse HTTPS affichée par JMH.
  2. Attends que la page de connexion JMH soit chargée.
  3. Appuie sur le menu ⋮, puis Installer et créer un raccourci → Installer. Selon la version de Chrome, le libellé peut être Installer l’application ou Ajouter à l’écran d’accueil.
  4. Confirme l’installation et garde le nom JMH.
  5. Ferme Chrome. Ouvre JMH depuis sa nouvelle icône et connecte-toi avec le compte JMH autorisé.

Ensuite, au quotidien

Active Tailscale, puis ouvre JMH. Tes imports et favoris passent par le NAS. Si Chrome propose seulement un raccourci qui ouvre un onglet, vérifie que tu utilises bien l’adresse HTTPS du NAS et recharge une fois la page avant de réessayer.

Vérifier depuis un autre réseau

Désactive le Wi-Fi, garde les données mobiles et Tailscale actifs, puis ouvre un fichier dans JMH. Tu peux ensuite refaire ce test sur le Wi-Fi de ton copain.

Le NAS doit rester allumé et connecté chez toi. La connexion Tailscale ne change pas ton pays de navigation : c’est l’accès privé au NAS.

Étapes : Aide officielle Chrome. Il s’agit d’une application web installable, sans publication de JMH dans le Play Store.

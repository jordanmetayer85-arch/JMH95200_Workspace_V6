JMH · Mise à jour 2026.10.02.2 · 2 octobre 2026

Fichiers, musique et connexion simplifiés

Installer sur chaque PC Windows

  1. Ouvre JMH et connecte-toi. La mise à jour est proposée depuis le NAS.
  2. Accepte la mise à jour. Tu peux aussi ouvrir JMH95200-Setup-2026.10.02.2.exe sur le bureau de ce PC. Pour le PC fixe, utilise sa proposition de mise à jour ou copie uniquement cet installateur.
  3. Si Windows le demande, ferme JMH puis relance l’installateur. Ouvre ensuite JMH.
  4. L’adresse du serveur reste http://192.168.1.27:3000. Tes fichiers, chansons, favoris et playlists restent sur le NAS.

Ajouter des chansons depuis mon PC

  1. Musiques → Ajouter des musiques.
  2. Choisir des musiques pour un ou plusieurs titres ; Choisir un dossier pour prendre tous les titres d’un dossier et de ses sous-dossiers.
  3. Clique sur Copier sur le NAS et ajouter. Laisse JMH ouvert pendant la copie.
  4. La progression et le bilan s’affichent. Les chansons sont dans Medias / Musique / Ajouts, avec les sous-dossiers sélectionnés, et apparaissent sur tes autres PC après actualisation de la bibliothèque.

Les originaux restent sur ton PC ou ton disque externe. Les copies identiques sont reconnues. Le bouton Arrêter après le titre en cours conserve ce qui est déjà importé.

Téléchargements de musique

L’importeur par lien enregistre désormais ses titres dans le même dossier Ajouts. Les anciens titres téléchargés ont été copiés et reclassés dans cette bibliothèque centrale, en conservant leurs fiches et favoris. Les anciennes copies NAS sont conservées comme secours.

Ouvrir mes fichiers

Clique sur le nom du fichier ou sur Ouvrir. Les images et textes s’affichent dans JMH ; les PDF disposent d’un aperçu. Avec le nouveau client Windows, les documents compatibles peuvent s’ouvrir dans leur application Windows. Si nécessaire, clique sur Télécharger sur ce PC, puis ouvre le fichier téléchargé. Le partage \\192.168.1.27\JMH doit être accessible dans l’Explorateur pour l’ouverture directe.

Enregistrer mes identifiants uniquement sur ce PC

  1. Dans le nouveau client Windows, sur l’écran de connexion, coche Enregistrer les identifiants sur ce PC.
  2. Entre tes identifiants, puis clique sur Se connecter.
  3. À la prochaine ouverture, l’écran de connexion reste affiché. Clique sur Remplir mes identifiants, puis sur Se connecter.
  4. Effacer sur ce PC supprime cette mémorisation locale.

Le mot de passe est chiffré avec la protection Windows dans le profil local JMH. Il n’est envoyé à aucun autre PC ni enregistré dans le NAS. L’enregistrement n’est pas disponible dans l’ancienne version Windows ni dans la version navigateur de JMH.

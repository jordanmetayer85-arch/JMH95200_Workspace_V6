1. Installer la nouvelle version sur le PC fixe

Ta précédente mise à jour est conservée. Celle-ci apporte les fonctions Windows : démarrage sans accélération graphique, mesures locales et commandes VPN.

  1. Sur le PC fixe, ouvre JMH et connecte-toi à ton compte habituel.
  2. Dans Mon espace → Mises à jour, vérifie que la version publiée porte le build 2026.10.02.1. Le mécanisme compatible peut lancer l’installation au prochain démarrage après connexion ; sinon, clique sur Installer depuis le serveur ou Télécharger l’installateur.
  3. Autre méthode : sur ce PC Dell, le fichier JMH95200-Setup-2026.10.02.1.exe est sur le bureau. Copie ce seul fichier sur une clé USB ou sur un dossier partagé du NAS, puis copie-le sur le bureau du PC fixe. Ne déplace pas tes films ou musiques.
  4. Ferme JMH sur le PC fixe avant l’installation manuelle. Double-clique sur l’installateur et suis sa fenêtre. L’installation conserve les données du compte Windows et les contenus du NAS. Cet installateur personnel n’a pas de signature commerciale.
  5. Relance JMH. Si la fenêtre de connexion apparaît, sélectionne le NAS et indique exactement http://192.168.1.27:3000. Si l’ancienne adresse du portable apparaît, ouvre la connexion avec Ctrl + Maj + S et remplace-la par l’adresse du NAS.
  6. Connecte-toi avec ton identifiant JMH habituel. Les identifiants TrueNAS servent uniquement à administrer le NAS.
  7. Ouvre Cet ordinateur : le nom du PC fixe doit apparaître. Le processeur, la RAM et la mémoire utilisée par JMH sont mesurés sur ce PC, pas sur le NAS. La première valeur CPU apparaît après un court délai.

Le build attendu est 2026.10.02.1. Si la page annonce qu’une mise à jour Windows est nécessaire pour les mesures ou les boutons VPN, le programme installé est encore ancien : installe le fichier ci-dessus puis relance-le.

2. Utiliser le VPN depuis JMH

  1. Vérifie que le NAS est allumé et accessible sur le réseau domestique.
  2. Ouvre VPN & Internet dans JMH. Le tunnel NAS doit être connecté et afficher une adresse de sortie Internet.
  3. Clique sur Activer sur ce PC. JMH vérifie le proxy HTTPS puis configure le proxy Windows pour ton compte, en sauvegardant les réglages d’origine.
  4. Dans Opera GX, désactive le VPN intégré Opera pendant l’utilisation ou la vérification de celui du NAS. Ferme et relance le navigateur ou actualise tes onglets pour les nouvelles connexions.
  5. Si le navigateur demande les identifiants du proxy 192.168.1.27:8888, clique sur Identifiants pour le navigateur dans la page VPN de JMH. Utilise les valeurs affichées, puis masque-les avec le même bouton. Ce ne sont ni ton mot de passe Proton ni ton mot de passe TrueNAS.
  6. Pour revenir à ta navigation normale, clique sur Désactiver sur ce PC. Les réglages Internet d’origine sont restaurés. Le tunnel du NAS peut rester connecté pour les autres PC.

Ce dispositif couvre les applications qui suivent le proxy Windows, notamment la navigation compatible. Il ne couvre pas tous les logiciels, les jeux, les connexions UDP ou tout le trafic Windows. Si le NAS est éteint pendant que le proxy est activé, la navigation par ce proxy sera bloquée : désactive le VPN sur ce PC.

Sur le bureau du Dell, le dossier VPN JMH contient aussi les raccourcis Activer le VPN, Désactiver le VPN et État du VPN. Les identifiants y sont conservés sous une forme protégée par ton compte Windows. Pour le PC fixe, utilise les boutons de JMH après la nouvelle mise à jour.

3. Changer de pays

Le profil fourni est États-Unis · Proton Free 56. La sortie vérifiée lors de la configuration était à New York. La localisation affichée peut varier suivant l’infrastructure de Proton.

  1. Connecte-toi à ton compte Proton VPN et génère un fichier WireGuard pour un serveur accessible avec ton abonnement.
  2. Dans JMH → VPN & Internet → Ajouter un profil Proton / gérer le tunnel, indique un nom, le code pays (US, CA, AU, etc.) et sélectionne le fichier .conf.
  3. Clique sur Ajouter le profil, choisis-le dans la liste des emplacements puis clique sur Appliquer cet emplacement.
  4. Attends le redémarrage du tunnel puis clique sur Actualiser. Le changement concerne tous les PC qui utilisent le VPN de ce NAS.

Un code pays n’ajoute pas un serveur : il faut son fichier WireGuard. L’offre gratuite ne fournit pas un choix illimité dans le monde ; l’Australie n’est pas garantie avec ton offre. La liste dans JMH contient uniquement les profils réellement importés. Les commandes Démarrer le tunnel NAS et Arrêter le tunnel pour tous sont réservées aux administrateurs. La seconde bloque les utilisateurs du proxy tant que le tunnel n’est pas redémarré.

4. Musique, thèmes et diagnostic du gel Windows

Le bouton ◐ en haut de JMH bascule entre clair et sombre pour ce navigateur/PC. Dans Mon espace → Paramètres → Apparence, un administrateur peut aussi régler le thème par défaut et l’accent, puis enregistrer. Le thème clair corrige les couleurs des pages musique et cinéma.

La nouvelle version Windows désactive l’accélération graphique. La lecture des formats comme WMA est préparée sur le NAS ; les réglages basses, médiums et aigus restent disponibles dans Régler le son. La file d’écoute, le minuteur et le retour à la bibliothèque restent accessibles.

Un gel complet de Windows ne permet pas de conclure à une cause unique. Le mode sans accélération graphique réduit une piste de blocage ; la résolution définitive sur le PC fixe reste à confirmer par son utilisation et ses journaux.

  1. Après la mise à jour, commence par un titre de musique et vérifie la lecture et le retour à la bibliothèque.
  2. Si Windows se fige à nouveau, note l’heure et ce que tu venais de lancer. Après le redémarrage, ouvre JMH → Cet ordinateur → Exporter le diagnostic Windows.
  3. Enregistre le fichier JSON sur le bureau du PC fixe et transmets-le ici. Il contient les événements Windows récents, les versions des pilotes graphiques et les mesures du PC. Il n’envoie rien automatiquement.

Les températures sont affichées seulement si un fournisseur compatible expose les capteurs (Libre Hardware Monitor ou Open Hardware Monitor). Sinon JMH indique températures indisponibles. Aucun pilote de capteurs n’a été installé automatiquement.

5. Importer une musique depuis un lien

  1. Avec un compte administrateur, ouvre Importer une musique dans JMH.
  2. Colle le lien HTTPS d’un titre YouTube ou YouTube Music public que tu peux télécharger. Un seul titre est traité à la fois ; les playlists ne sont pas téléchargées.
  3. Clique sur Télécharger sur le NAS et attends le statut. Le serveur traite la demande sans garder le PC allumé pendant le travail.
  4. Un import réussi apparaît dans la bibliothèque musicale. Actualise celle-ci en revenant sur Musiques. Le fichier se trouve aussi dans JMH / Telechargements / Musique, avec un nom technique unique ; les métadonnées musicales sont conservées lorsqu’elles sont disponibles.

Le moteur d’import et son lancement sur le NAS ont été vérifiés. Aucun titre de ton compte n’a été téléchargé pendant les tests. YouTube peut refuser les accès depuis le NAS ; l’erreur est affichée dans JMH. L’outil ne récupère pas les téléchargements hors connexion de l’application officielle, les fichiers protégés ou les titres réservés à un compte. Fonctionnement officiel du mode hors connexion.

6. Tes originaux et la copie sur le NAS

Les originaux de My Passport, E: / Films et E: / Music sont conservés. Aucun déplacement ni suppression sur le disque externe n’est effectué. La bibliothèque utilise les copies du NAS.

La copie des films s’était interrompue pendant la nuit. La reprise ne recopie que ce qui manque ou reste incomplet. La musique est déjà copiée ; le transfert affiche son état dans JMH. Pour que la copie puisse continuer, garde le Dell, le NAS et le disque externe allumés et connectés jusqu’au message de vérification terminée. Cette présence du Dell est nécessaire au transfert depuis son disque USB, pas au fonctionnement normal de JMH une fois les fichiers copiés.

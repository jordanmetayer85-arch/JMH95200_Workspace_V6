JMH · COMPTE PROPRIÉTAIRE

Superviser ton application.

Le panneau de contrôle, la double authentification et les demandes de récupération, pas à pas.

Ce guide ne contient ni mot de passe ni clé de récupération. Le compte Propriétaire est distinct du compte administrateur. Son panneau permet de gérer les comptes et les contenus ; il ne charge pas automatiquement les bibliothèques musicales ou les films.

1. Première connexion

  1. Ferme puis rouvre JMH pour charger l’interface à jour. Sur ton réseau domestique, l’adresse reste https://192.168.1.27:3443.
  2. Dans la connexion, saisis l’identifiant Propriétaire et le mot de passe aléatoire qui t’ont été remis. Tu peux cocher la mémorisation sur ton ordinateur personnel : le mot de passe sera conservé chiffré localement après la connexion complète.
  3. Clique sur Se connecter. Le formulaire de configuration du Propriétaire apparaît ; le mot de passe seul ne donne pas accès au panneau.
  4. Indique le nom que tu souhaites afficher comme responsable de cette installation.
  5. Scanne le QR code de l’étape 2 avec ton téléphone pour ajouter JMH Propriétaire dans Mots de passe ou ton authentificateur. Sinon, ouvre ton application d’authentification. Choisis Ajouter un compte, puis l’option pour saisir une clé de configuration manuellement.
  6. Donne au compte le nom JMH Propriétaire. Recopie la clé de configuration affichée dans JMH. Choisis un code basé sur le temps, à 6 chiffres, renouvelé toutes les 30 secondes.
  7. Conserve la clé de récupération qui commence par JMH-OWNER- dans un endroit protégé, séparé du téléphone et du NAS. Coche la confirmation uniquement après l’avoir sauvegardée. Elle ne sera plus réaffichée.
  8. Lis et confirme les règles de supervision. Saisis le code à 6 chiffres de ton téléphone, puis clique sur Terminer la configuration.

Pour les connexions suivantes, choisis ton compte enregistré, clique sur Se connecter, puis indique le code de ton authentificateur. Un code déjà utilisé ne peut pas être réutilisé : attends le suivant si nécessaire. L’heure du téléphone doit être automatique.

Renouveler une clé de récupération non conservée

Connecte-toi au panneau Propriétaire, puis ouvre Sécurité du Propriétaire → Générer une nouvelle clé de récupération. Saisis un nouveau code à six chiffres de ton téléphone. Si tu viens de te connecter, attends que le code change. Copie ou note la nouvelle clé, conserve-la séparément du téléphone, puis coche la confirmation avant de fermer. L’ancienne clé est révoquée ; le mot de passe et la configuration de l’authentificateur ne changent pas. La clé permet de récupérer un mot de passe oublié avec un code de l’authentificateur ; elle ne remplace pas à elle seule un téléphone perdu.

2. Retrouver le compte en cas d’oubli

  1. Sur la page de connexion, ouvre le petit panneau d’aide, puis Propriétaire : mot de passe oublié.
  2. Indique ton identifiant, ta clé de récupération personnelle et un code actuel de ton authentificateur.
  3. Clique sur Vérifier et régénérer. JMH génère un nouveau mot de passe aléatoire et une nouvelle clé de récupération ; les anciennes valeurs et les anciennes sessions sont révoquées.
  4. Sauvegarde les deux nouvelles valeurs avant de fermer la fenêtre. Clique sur Utiliser ces identifiants, puis connecte-toi avec un nouveau code de ton authentificateur.

La clé de récupération et le téléphone sont tous les deux nécessaires à cette procédure. Si tu perds tous tes moyens d’accès, la récupération en ligne ne pourra pas vérifier ton identité : une intervention contrôlée de l’opérateur du NAS sera nécessaire. Les administrateurs JMH ne peuvent pas réinitialiser ce compte.

3. Comptes et restrictions

Ouvre Comptes et accès pour créer des comptes, attribuer les rubriques, changer leur rôle, générer un code provisoire ou désactiver un compte. Un nouveau compte personnel commence sans accès ; son titulaire choisit son propre mot de passe après le code d’activation.

Restreindre temporairement coupe les sessions ouvertes et bloque la connexion pour 1, 2, 24, 48 ou 72 heures. Le motif et la fin de restriction sont affichés à la personne. Tu peux lever la restriction avant son échéance. Retirer un compte ne supprime pas ses fichiers.

4. Examiner et censurer un contenu

  1. Ouvre Contenus du NAS pour les fichiers ordinaires, ou Coffres supervisés pour un coffre qui a accepté la supervision.
  2. Clique sur un fichier pour l’examiner. Les lecteurs intégrés fonctionnent pour les formats compatibles avec ton appareil ; les autres fichiers peuvent être téléchargés.
  3. Choisis Censurer et indique un motif compréhensible pour son détenteur. Dans JMH, ses lectures et téléchargements sont bloqués.
  4. La rubrique Modération permet de voir les restrictions et de lever une censure.

La censure agit dans JMH. Elle ne peut pas rappeler une copie déjà téléchargée ni bloquer un accès direct autorisé au partage NAS. Les déplacements se font sans écraser un fichier existant. Le disque dur externe n’est pas une cible de suppression de ce panneau.

5. Coffres sensibles : deux situations

Les nouveaux coffres sont supervisés. Avant leur création, la personne doit confirmer que le Propriétaire pourra consulter et modérer leurs contenus. Ils restent chiffrés sur le NAS, avec un accès de supervision prévu explicitement.

Les anciens coffres attendent l’autorisation de leur détenteur et son premier déverrouillage. Lors de la première ouverture, leur détenteur doit autoriser la supervision dans la fenêtre affichée, puis saisir le mot de passe habituel de son coffre. La conversion se fait automatiquement sans changer ce mot de passe ni sa clé personnelle. Refuser bloque l’accès au coffre dans JMH sans supprimer ses fichiers. Le Propriétaire connecté peut ensuite le consulter sans saisir de mot de passe ou de clé de coffre supplémentaire. La conversion ne déplace ni ne supprime ses fichiers. Après conversion, la supervision ne peut pas être retirée depuis ce compte.

Le Propriétaire ne reçoit pas les mots de passe personnels et l’interface ne lui affiche pas les clés de secours des utilisateurs. Les anciens coffres non convertis ne peuvent pas être lus avec ce rôle.

6. Corbeille protégée et récupération

  1. Le bouton Corbeille retire le contenu de son emplacement actif et le place dans un stockage hors du partage de fichiers. Seul le Propriétaire peut consulter cette corbeille.
  2. La personne ouvre Paramètres → Mon compte → Mes demandes de récupération. Elle choisit le document, explique pourquoi elle le demande et précise son usage ou les modifications proposées.
  3. Une alerte apparaît dans Demandes de récupération du panneau Propriétaire. Examine le rapport et, si nécessaire, le contenu dans la corbeille.
  4. Accepter demande une explication et une confirmation. Un fichier ordinaire revient dans Utilisateurs / identifiant / Restaurations. Un fichier de coffre supervisé revient dans son coffre d’origine.
  5. Refuser et supprimer définitivement demande aussi une explication et une confirmation explicite. La copie active de la corbeille est supprimée ; la personne retrouve la décision et le motif dans ses demandes.

Une suppression définitive de la copie active JMH n’est pas un effacement garanti de toutes les copies : des sauvegardes, des instantanés du NAS ou des téléchargements antérieurs peuvent encore exister. Ce panneau ne détruit pas les sauvegardes et ne promet pas qu’un fichier ne pourra jamais être récupéré.

7. Journal et sécurité

Journal · dernières 24 heures présente les connexions, les opérations sur les fichiers, les changements de droits et les décisions de modération, avec des pages de 100 événements. Le Propriétaire y voit aussi ses propres actions. Aucun mot de passe, clé de récupération ou secret d’authentification n’y est enregistré.

Les coffres et la corbeille sont protégés au niveau de JMH. L’opérateur qui contrôle le système du NAS reste techniquement maître de ses fichiers et de son logiciel. Ferme ta session Propriétaire après utilisation et conserve tes moyens de récupération séparément.

Installer JMH sur iPhone

Tes adresses à conserver

Application : https://jmh-nas.tailee93eb.ts.net
Fichiers du NAS : smb://100.80.184.88
Partage Windows : \\100.80.184.88\JMH

Active Tailscale sur l’appareil avant d’utiliser ces adresses.

JMH s’installe comme une application web : une icône JMH, puis une fenêtre indépendante. Le navigateur est utilisé une seule fois pour l’ajouter. La bibliothèque reste sur le NAS ; elle n’est pas copiée entièrement sur le téléphone.

Avant l’installation

  1. Le NAS est déjà configuré. Le tutoriel Accès NAS depuis l’extérieur explique comment connecter tes appareils au réseau Tailscale.
  2. Installe Tailscale depuis le magasin d’applications du téléphone. Connecte-le à ton réseau Tailscale. Pour ta copine, invite son propre compte depuis la console Tailscale plutôt que de partager ton mot de passe.
  3. Active Tailscale. Sur l’iPhone, accepte l’ajout de la configuration VPN quand iOS le demande.
  4. Dans la page Accès à distance de JMH, récupère l’adresse HTTPS affichée après la liaison du NAS. Conserve cette adresse pour chez toi et ailleurs. L’ancienne adresse 192.168.1.27 ne fonctionne que chez toi.

Ajouter JMH sur l’iPhone

  1. Ouvre Safari et saisis l’adresse HTTPS du NAS indiquée dans JMH.
  2. La page de connexion JMH apparaît. Ouvre le bouton Partager (carré avec une flèche), ou le menu de la page puis Partager, selon la disposition de Safari.
  3. Fais défiler les actions et choisis Sur l’écran d’accueil. Si cette action manque, choisis Modifier les actions et ajoute-la.
  4. Laisse le nom JMH. Si l’option est proposée, active Ouvrir comme app web, puis touche Ajouter.
  5. Ferme Safari. Touche maintenant l’icône JMH sur l’écran d’accueil et connecte-toi avec ton compte JMH.

Ensuite, au quotidien

Active Tailscale, puis touche JMH. Tes chansons, films et fichiers restent sur le NAS, comme sur tes PC. Les nouvelles fonctionnalités de l’interface arrivent depuis le NAS à la prochaine ouverture connectée.

Vérifier l’accès à l’extérieur

Désactive le Wi-Fi de l’iPhone, garde les données mobiles et Tailscale actifs, puis ouvre JMH. Si tu peux ouvrir un fichier et écouter un titre, ton accès fonctionne hors de chez toi.

Le NAS et la connexion Internet de la maison doivent rester actifs. Les films nécessitent un débit suffisant ; certains formats ne peuvent pas être lus directement sur iPhone et nécessitent une application compatible après téléchargement.

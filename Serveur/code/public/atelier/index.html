SIMPLEMENT, ÉTAPE PAR ÉTAPE

Ton atelier, partout.

  1. Discuter : écris ou dicte ton message, relis-le puis clique sur Envoyer. Cette partie fonctionne directement dans JMH sur ordinateur et téléphone.
  2. Coder et piloter : sur Windows, installe une fois le connecteur ci-dessous et utilise le client JMH à jour. Les actions s’exécutent sur le PC que tu utilises, jamais sur les autres appareils.
  3. Autorisations : ton administrateur doit activer « Outils du PC » pour ton compte. Les nouveaux comptes restent restreints.
  4. Arrêter : utilise Arrêter le pilotage, depuis la conversation. Arrête la session avant de quitter JMH.

Le microphone ajoute du texte pour relecture, sans envoyer automatiquement le message. Windows ou le navigateur gère la reconnaissance vocale et peut traiter la voix en ligne.

L’application Atelier IA reste aussi accessible avec son icône sur le Bureau. Le contrôle visuel de Windows ne remplace pas les validations administrateur ou les connexions que tu dois effectuer toi-même.

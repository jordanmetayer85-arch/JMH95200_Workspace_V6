Mes fichiers NAS sur mon iPhone

À faire chez toi, avec le NAS allumé et l’iPhone sur le même Wi-Fi que tes ordinateurs.
  1. Ouvre l’application Fichiers sur ton iPhone.
  2. Appuie sur Explorer. Si nécessaire, appuie une deuxième fois pour voir les emplacements.
  3. En haut, appuie sur les trois points …, puis sur Se connecter au serveur.
  4. Dans « Serveur », écris :
    smb://192.168.1.27
    Puis appuie sur Se connecter.
  5. Choisis Utilisateur référencé. Nom : jmh.
    Utilise le mot de passe du partage indiqué dans ton tutoriel privé sur le bureau du PC.
    Appuie sur Suivant.
  6. Ouvre JMH, puis Medias.
    Musique contient les chansons ; Films contient les films.
  7. Touche un fichier pour l’ouvrir. Les formats reconnus par l’iPhone s’affichent directement ; les autres nécessitent une application compatible.

Les prochaines fois

Retourne dans Fichiers → Explorer, puis touche le serveur dans les emplacements partagés. Tu peux aussi le retrouver dans les serveurs récents.

Si la connexion échoue

Vérifie le Wi-Fi de la maison et le NAS allumé. Saisis bien smb://. Le compte des fichiers est jmh ; ce n’est pas le compte administrateur TrueNAS.

Cette connexion est prévue sur ton réseau de maison. Le VPN Proton du NAS ne crée pas un accès à tes fichiers depuis l’extérieur.

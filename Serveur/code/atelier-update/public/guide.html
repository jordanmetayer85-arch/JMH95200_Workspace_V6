GUIDE DE DÉMARRAGE · 23 OCTOBRE 2026

Ton atelier d’intelligence artificielle.

Ce programme reprend le principe de la vidéo du NAS : une passerelle OmniRoute rassemble les fournisseurs que tu connectes, puis peut passer à un autre modèle éligible si une connexion atteint sa limite.

1. Ouvrir l’application

Double-clique sur Atelier IA sur le Bureau du portable. Le moteur démarre à la demande. Attends le voyant Moteur prêt. Rien n’est à installer dans ton NAS.

2. Créer ta clé gratuite Gemini

  1. Dans Atelier IA, clique sur Connexions, puis Ouvrir Google AI Studio.
  2. Connecte-toi toi-même à ton compte Google.
  3. Dans la page des clés API, choisis Créer une clé API, puis crée ou sélectionne un projet. Les intitulés de Google peuvent évoluer.
  4. Choisis un projet utilisant le niveau gratuit, sans facturation associée. N’active pas de facturation ni d’essai payant si tu veux rester dans les quotas gratuits. Google peut imposer des conditions d’éligibilité.
  5. Copie la clé. Reviens dans Atelier IA, colle-la dans Clé API Gemini, coche la confirmation du projet sans facturation, puis clique sur Enregistrer Gemini.
  6. Dans Discuter, envoie par exemple « Réponds bonjour ». Cette première réponse vérifie la connexion et la disponibilité réelle de ton quota.

Tu n’as pas besoin de partager cette clé dans une conversation. Elle permet d’utiliser ton projet Google : garde-la privée. Si elle fuit, révoque-la dans Google AI Studio et crée une nouvelle clé.

3. Discuter

Écris ton message, puis clique sur Envoyer. Entrée envoie ; Maj + Entrée insère une ligne. Choisis Conversation · gratuit ou Code · gratuit. La réponse apparaît progressivement. Interrompre arrête la demande en cours ; Nouvelle discussion efface l’historique de cette fenêtre.

Les échanges restent en mémoire dans cette page et disparaissent en la fermant. Ils sont néanmoins transmis au fournisseur pour produire les réponses. Le niveau gratuit Google peut utiliser les données pour améliorer ses produits, selon ses conditions et ta région. Évite d’y envoyer des fichiers sensibles.

Dicter un message

Clique sur le petit microphone près d’Envoyer, puis accepte le traitement vocal proposé si tu es d’accord. Sous Windows, le volet de dictée Windows s’ouvre dans le champ. Parle, arrête son micro, puis relis le texte avant Envoyer. Sur un navigateur compatible, le bouton permet de démarrer et arrêter la reconnaissance vocale. Aucun message n’est envoyé automatiquement.

4. Créer une application avec Claude Code

  1. Clique sur Coder un projet.
  2. Donne un nom à ton projet, puis clique sur Ouvrir le projet.
  3. Le terminal officiel Claude Code s’ouvre. Lors du premier usage, lis et valide les écrans d’accueil et l’autorisation du dossier si tu es d’accord.
  4. Décris précisément ce que tu veux créer. Vérifie les demandes d’accès aux fichiers et d’exécution des commandes avant de les confirmer.

Les projets se trouvent dans Documents\Atelier IA\Mes projets. L’outil utilise le mode auto/coding:free d’OmniRoute. Cela peut être Gemini ou un autre modèle gratuit autorisé : ce n’est pas une promesse d’accès gratuit à un modèle Claude payant. Anthropic ne prend pas en charge l’utilisation de Claude Code avec des modèles non-Claude ; certaines fonctions ou certains modèles peuvent être incompatibles.

Piloter la souris et les fenêtres

Le bouton Piloter mon PC démarre une session visuelle avec Gemini. Le chat ordinaire reste sans contrôle du PC. Lire le guide de pilotage et les raccourcis d’arrêt.

5. Ajouter d’autres fournisseurs et le basculement

Ouvre Tableau de bord OmniRoute → Providers pour connecter d’autres fournisseurs avec tes propres accès autorisés. Les modes gratuits sélectionnent les modèles marqués éligibles et passent à une autre connexion disponible. Avec seulement Gemini, il n’y a pas de second fournisseur de secours. Les limites par compte ou projet continuent à s’appliquer ; plusieurs connexions ne garantissent pas un accès permanent.

Les fonctions de compression et les combinaisons avancées se règlent dans OmniRoute. Elles sont facultatives ; leur efficacité dépend du texte et du modèle. La compression agressive n’est pas activée automatiquement, pour éviter de dégrader les instructions.

6. Fermer et relancer

Le bouton Arrêter le moteur ferme proprement le service local. Fermer uniquement l’onglet laisse le moteur tourner pour Claude Code. Pour reprendre, double-clique sur l’icône du Bureau. Aucun démarrage automatique avec Windows n’a été ajouté.

Si quelque chose bloque

  • Moteur encore en démarrage : laisse quelques secondes au premier lancement. S’il reste bloqué, arrête l’atelier, puis relance-le.
  • Pas de modèle disponible : vérifie la clé API et le quota du projet dans Google AI Studio. Un modèle peut être absent du niveau gratuit ou non disponible dans ta région.
  • Quota atteint : attends son renouvellement, ou connecte un autre fournisseur dont l’offre te convient. Le programme ne débloque pas un quota épuisé.
  • Accès local refusé : ouvre l’application depuis son icône sur le Bureau, qui transmet son autorisation locale.
  • Terminal Claude Code : le moteur Atelier IA doit rester actif. Une première confirmation du dossier ou du terminal peut être nécessaire.
  • Changer de clé : dans OmniRoute → Providers, retire l’ancienne connexion puis ajoute ta nouvelle clé dans Atelier IA. Révoque chez Google toute clé que tu ne veux plus utiliser.

Où sont les données ?

Le programme est installé dans Documents\Atelier IA\Application. Les paramètres et connexions sont dans son dossier data, protégé par les autorisations de ton compte Windows. Le moteur écoute uniquement sur 127.0.0.1 : aucun port de la box n’a été ouvert. Les clés fournisseurs sont chiffrées par OmniRoute, mais une personne ayant le contrôle de ton compte Windows peut utiliser les accès de cet ordinateur. Ne copie pas le dossier data sur une clé USB ou sur un partage public.

OmniRoute 3.8.52 et Claude Code 2.1.309 sont installés dans des dossiers dédiés. Les réglages globaux de Codex et les connexions de JMH ne sont pas modifiés. Les futures mises à jour de cet atelier devront être vérifiées et installées séparément.

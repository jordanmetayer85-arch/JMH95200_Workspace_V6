PILOTAGE VISUEL · GUIDE PERSONNEL

La souris, le clavier et les fenêtres.

Ce mode relie le client Claude Code à ton Gemini via OmniRoute et au connecteur Windows-MCP. L’IA peut observer l’écran et effectuer des actions dans Windows avec les droits de ton compte. Elle agit sur ton vrai ordinateur.

1. Lancer une session

  1. Ouvre Atelier IA depuis le Bureau et attends Moteur prêt.
  2. Ferme ou masque tes documents confidentiels, mots de passe et conversations privées.
  3. Dans Discuter, clique sur Piloter mon PC.
  4. Lis le panneau et coche l’autorisation d’envoyer les captures de cette session à Gemini (Google). Clique sur Démarrer la session.
  5. Une fenêtre de commande Claude Code s’ouvre. Lors du premier lancement, confirme le thème et la confiance dans le dossier de travail si ces écrans sont proposés. Aucun compte Anthropic supplémentaire n’est à fournir : le modèle est ton Gemini.
  6. Écris ta demande en français. Exemple : « Observe la fenêtre ouverte et explique-moi les boutons. N’agis pas encore. »
  7. Lis les demandes d’autorisation avant les outils de clic, saisie ou gestion des fenêtres. Autorise une action ponctuelle si elle correspond à ta demande. Évite une autorisation générale si tu ne souhaites pas donner carte blanche.

2. Faire un premier essai simple

Ouvre la page de démonstration dans une fenêtre visible. Demande à l’IA : « Dans la page Démonstration de pilotage, clique une fois sur Ajouter un point. Observe ensuite le résultat et arrête-toi. » Le compteur doit passer de 0 à 1. Cette page ne contient aucun fichier personnel et n’enregistre rien.

3. Reprendre la main et arrêter

  • Interrompre la prise de souris : bouge franchement la souris ou presse Ctrl + Alt + Maj + Retour arrière. Le connecteur donne la priorité à ton intervention ; sa temporisation technique peut le rendre disponible à nouveau après 10 secondes d’inactivité. Ce n’est donc pas un arrêt définitif.
  • Terminer directement : reviens dans Atelier IA et clique sur Arrêter le pilotage, dans la barre de gauche. Cela ferme la fenêtre de la session et ses processus de contrôle.
  • Depuis la fenêtre de commande : Ctrl+C interrompt la demande. Écris ensuite /exit pour quitter Claude Code.
  • Fermer seulement la page Atelier IA ne ferme pas la session. Utilise le bouton d’arrêt ou quitte la fenêtre de commande.

4. Ce qui est configuré

Le connecteur démarre à la demande et communique directement avec Claude Code, sans ouvrir de port réseau supplémentaire. Il n’est pas lancé au démarrage de Windows. Son analyse statistique est désactivée. Le mode pilotage expose les outils d’observation et d’interface ; les outils PowerShell, registre et manipulation directe de fichiers du connecteur sont exclus, et les outils de code habituels de Claude Code sont désactivés dans ce mode.

Les captures et descriptions de l’écran nécessaires au raisonnement passent par OmniRoute vers Gemini. Le compte et les quotas Google habituels restent nécessaires. Les conversations du client peuvent rester dans son profil local, dans Documents\Atelier IA\Application\data\desktop-profile. Ce mode n’est pas un bac à sable : les clics peuvent modifier les vraies applications. Il ne contrôle pas l’écran sécurisé Windows, les demandes administrateur ou un PC éteint. Pour les authentifications, reprends toi-même la main.

Si une commande ne fonctionne pas

  • USER_CONTROL : tu as repris la souris. Donne une nouvelle instruction explicite lorsque tu veux continuer.
  • Connecteur absent : dans la session, tape /mcp pour vérifier windows-visual, puis quitte et relance le pilotage si nécessaire.
  • Quota ou modèle indisponible : vérifie Gemini dans Connexions et les limites de ton compte Google. Le mode ne donne pas de crédits illimités.
  • Coordonnées incorrectes : demande une nouvelle observation de l’écran avant de cliquer. Les fenêtres et la résolution peuvent avoir changé.

La compatibilité d’un modèle Gemini avec Claude Code dépend de la passerelle ; Anthropic ne prend pas en charge les modèles non-Claude. Les tests de connexion ne garantissent pas que chaque tâche visuelle réussira.

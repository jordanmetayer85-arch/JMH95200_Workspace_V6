SIMPLE, ÉTAPE PAR ÉTAPE

Ton atelier, en quelques clics.

Retrouve ici le fonctionnement présenté dans la vidéo, avec ses limites réelles.

01

Ouvrir l’atelier

Double-clique sur Atelier IA sur le Bureau. Le moteur local démarre automatiquement. Le voyant en haut indique quand il est prêt.

02

Connecter Gemini

Dans Connexions, crée puis colle ta clé Google. Tu le fais une seule fois sur cet ordinateur. Le mot de passe de ton compte Google reste chez Google.

03

Discuter ou coder

Écris une demande dans Discuter. Pour créer des fichiers, utilise Coder un projet : Claude Code s’ouvre dans un dossier de projet séparé et demande les autorisations nécessaires.

04

Ajouter d’autres IA

Le tableau de bord OmniRoute permet d’ajouter tes autres fournisseurs et de suivre leurs quotas. Les modèles disponibles et leurs conditions évoluent.

✦

Ce que la vidéo simplifie

OmniRoute est gratuit et libre. Il ne fournit pas de crédits et ne transforme pas Gemini en Claude. Le terminal Claude Code peut utiliser une passerelle compatible ; Anthropic ne prend pas en charge son utilisation avec des modèles non-Claude. La qualité et les outils disponibles dépendent du modèle. L’application locale a besoin d’Internet pour joindre le fournisseur.

Ton PC, sous ton contrôle.

Le mode pilotage s’active directement dans cette conversation. Ensuite, écris ici ce que tu veux faire : l’IA pourra voir l’écran, cliquer, écrire et gérer les fenêtres.

Garder la main

Bouge franchement la souris ou presse Ctrl + Alt + Maj + Retour arrière pour reprendre la main. Tu peux arrêter le pilotage à tout moment avec le bouton Arrêter dans Atelier IA. Pour les actions sensibles (suppression, achat, envoi à un tiers, sécurité ou réseau), l’agent doit demander ta confirmation.

Cette autorisation vaut pour la session de pilotage que tu démarres volontairement. Aucun service de contrôle ne tourne au démarrage de Windows. Ce mode agit sur le vrai PC avec Windows-MCP. Les clics et la saisie affichent une demande Autoriser / Refuser. Le plugin Computer Use de Codex n’est pas embarqué.
